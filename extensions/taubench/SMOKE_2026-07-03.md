# tau-bench live plumbing smoke — 2026-07-03

Live plumbing test of the plain baseline: **no faults armed, no monitor, no qualification.**
Purpose is to prove the live path works and that OUR cost metering + the hard spend cap
behave, and to price a future qualification phase. Runner: `extensions/taubench/live_smoke.py`.

## Configuration

| | |
|---|---|
| Agent | `anthropic / claude-haiku-4-5`, tool_calling_agent, temperature 0.0, max_steps 30 (stock) |
| User simulator | `openai / gpt-4o`, strategy `llm`, temperature stock |
| Wrapper | `FaultedEnv` with an **empty fault set** (inert-in-live-path check) |
| Hard cap | **$2.00**, enforced in code by a projected-cost guard inside the litellm wrapper |
| Cost source | OUR `CostMeter(strict=False)`, read from litellm `response_cost` + `usage` (never tau-bench `get_total_cost`) |
| Tasks | 3 lowest ground-truth-action tasks in the retail test split: **50, 70, 73** |

## Result: PASS — plumbing healthy, cap never approached

- **3/3 episodes completed**, no blocker, no fallback (the Anthropic key + Haiku pricing both
  worked, so the option-3 fallback was not needed).
- **Total spend $0.2164** of the $2.00 cap (`cap_ok = true`). The projected-cost guard was
  never triggered — we finished at ~11% of the cap.
- **`fault_active` was False in every episode**; zero `fault_fire` events; `tools_map` stayed
  pristine. The wrapper is provably inert in the live path (see "Surprise 1" on the `armed` flag).

## Extrapolation to the study (sanity-check vs the $40–120 envelope)

Measured mean is **$0.072/episode**, but **these are the three shortest tasks**, so treat it as
a **floor**, not the study mean.

| Basis | 400 episodes | 600 episodes |
|---|---:|---:|
| Floor (mean of shortest tasks, $0.072) | $28.8 | $43.3 |
| Mid-length proxy (task 70, $0.105) | $41.8 | $62.7 |

**Verdict: does not bust the $40–120 envelope.** The floor sits at/below the $40 low end; a
representative mid-length estimate ($42–63) sits comfortably inside; only a study weighted
heavily toward long (15–30 step) tasks and injected-arm struggle would approach the $120 top.

**Caveats on the extrapolation (flagged for ratification):**
1. **Selection floor.** Tonight's tasks are the lowest-action tasks; a representative estimate
   must sample the full task-length distribution, which will raise the mean.
2. **Agent cost dominates (88%) and scales with steps.** The retail wiki (~10k-token system
   prompt) is re-sent every agent turn and history grows, so per-episode cost rises
   ~super-linearly with step count. This is inherent to `tool_calling_agent`.
3. **Injected episodes will cost more than clean.** A fault makes the agent retry/struggle →
   more steps → more tokens. Qualification runs **both** clean and injected arms × k trials, so
   the injected-cell mean exceeds tonight's clean floor.
4. **The draft's suggested $40 qualification-phase cap may be tight.** A 400–600 episode
   qualification across both arms could land at $40–65+ once (1)–(3) are folded in; consider
   $50–60 at ratification, still inside the $150 study envelope.

## Surprises / notes

1. **`armed` is True in every clean-episode trace — by design, not a fault.** `armed` is the
   episode-level disarm-invariant flag (set at reset, cleared before reward). It is orthogonal
   to whether a fault is active. With an empty fault set, **`fault_active` is always False**, no
   `fault_fire` event is ever emitted, and `tools_map` stays pristine — which is what the smoke
   asserts. (The brief's "assert armed is never true" is operationalized as `fault_active`,
   which is the fault-activity signal; the raw `armed` flag stays True during any episode.)
2. **Agent carries ~88% of cost** because it re-sends the wiki each turn; the user sim is cheap
   (short turns) despite gpt-4o's higher per-token price.
3. **All three clean episodes passed (native reward 1.0).** The clean side of the qualification
   rule is satisfiable by a competent Haiku baseline on these tasks — a good early signal,
   though only short tasks were exercised.
4. **45 LLM calls for 3 short episodes.** The user sim adds calls (one reset per episode plus
   each `respond` turn); the metering wrapper split agent vs user correctly by the presence of
   the `tools` kwarg.

## What this smoke did NOT do

No fault armed; no injected episode; no monitor; no qualification; no verdict. Those remain

qualification draft's `[DECISION]` slots as smoke-tested, binding only at ratification.
